## Description

API de gestion de factures et dépenses personnelles avec authentification JWT.

## Technologies

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT Authentication

## Installation

```bash
pip install -r requirements.txt
```

## Configuration

Copier `.env.example` vers `.env` et configurer les variables d'environnement.

## Démarrage

```bash
uvicorn app.main:app --reload
```
